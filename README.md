# skills

My personal collection of agent skills, compatible with the
[vercel-labs/skills](https://github.com/vercel-labs/skills) CLI and the
[Agent Skills specification](https://agentskills.io).

## Install

```bash
npx skills add sebbefagerstedt/skills
```

## Layout

Each skill lives in its own directory under `skills/`, containing a `SKILL.md`
file with YAML frontmatter (`name`, `description`) describing what it does and
when to use it. See [skills/README.md](skills/README.md) for details.
